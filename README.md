# QuestLog 🎮

> **"Letterboxd for Games"** - Track your gaming journey with a beautiful mobile-first app

A gamified video game journal with 500k+ games from IGDB, personal ratings, and activity tracking.

## ✨ What's Working

- 🔍 **Search 500k+ games** from IGDB database
- ⭐ **Rate & review** games with personal 1-10 ratings
- 📚 **Track your library** with status filters (Playing, Completed, Plan to Play, Dropped)
- � **Activity log** shows your recent 10 gaming actions
- ⚡ **Instant loading** with smart caching (Library loads in 0ms from cache)
- 🎨 **Retro UI** inspired by handheld consoles
- � **Google OAuth** or email/password authentication
- ☁️ **Cloud sync** across all your devices

## 🛠️ Tech Stack

- **React Native + Expo** - Mobile-first cross-platform
- **Supabase** - Backend (PostgreSQL, Auth, Edge Functions)
- **IGDB API** - 500k+ games database
- **TypeScript** - Type-safe development
